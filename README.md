# coding village Admin Panel

A modern LeetCode-style admin console built with React, Vite, Tailwind CSS and Lucide icons.

## Included
- Responsive sidebar + top navigation
- Dashboard with KPI cards, activity chart, topic mix, recent submissions
- Problem management table with search, difficulty filter, multi-select, publish action UI and delete
- Create Problem modal with statement, examples, constraints and judge test-case controls
- Users management
- Submissions monitoring + export UI
- Contest, Analytics and Settings workspaces
- Mock data and local state so the UI is immediately interactive

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Backend integration next
Replace the mock state/data with REST/GraphQL endpoints for authentication, problems, test cases, submissions, users, contests, roles/permissions and analytics.
